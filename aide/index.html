Une question ? On t’aide.

Le launcher

Le launcher est-il gratuit ?
Oui. Le launcher est gratuit : tu ne paies que les jeux que tu choisis. Télécharger le launcher.
Sur quel ordinateur fonctionne-t-il ?
Sur un PC Windows 10 ou 11 en 64 bits, avec une connexion Internet.
Windows affiche « Windows a protégé votre ordinateur »
C’est normal pour un logiciel récent. Clique sur « Informations complémentaires », puis sur « Exécuter quand même ».
Comment mettre à jour le launcher et mes jeux ?
Tu n’as rien à faire : le launcher se met à jour tout seul et te propose les mises à jour de tes jeux.
Le téléchargement échoue
Nos fichiers sont hébergés par GitHub. En cas d’incident chez eux, un bandeau s’affiche sur la page de téléchargement : réessaie quelques minutes plus tard.

Compte et achats

Mon compte du site est-il le même que celui du launcher ?
Oui, c’est le même compte AstroLabs. Un jeu acheté sur le site apparaît dans le launcher dès que tu t’y connectes.
Comment acheter un jeu ?
Sur sa fiche, clique sur « Acheter » : le paiement se fait sur une page sécurisée Stripe. Tu peux aussi acheter directement dans le launcher. Voir les jeux.
J’ai payé mais le jeu n’apparaît pas
La confirmation prend en général quelques secondes. Vérifie que tu es connecté avec le même compte, puis relance le launcher. Si le jeu n’apparaît toujours pas, écris-nous avec l’adresse e-mail de ton compte.
Je n’ai pas reçu le code de vérification
Regarde dans tes courriers indésirables. Tu peux demander un nouveau code depuis l’écran de vérification (une fois par minute). Le code est valable 15 minutes.
J’ai oublié mon mot de passe
Utilise ton code de secours (16 caractères, donné à la création du compte) dans « Mot de passe oublié » sur la page compte. Un nouveau code de secours t’est alors donné.
J’ai perdu mon code de secours
Écris-nous depuis l’adresse e-mail de ton compte : nous vérifierons qu’il t’appartient avant de t’aider.

Le live TikTok

Comment le jeu réagit-il à mon live ?
Les cadeaux, likes et abonnements de tes spectateurs déclenchent des événements dans le jeu, en direct. Les réglages se font dans le jeu.
Quelle source de live choisir ?
Le jeu reçoit ton live de deux façons, au choix, dans l’onglet TIKTOK de ses paramètres :
  • EulerStream : connexion directe avec ton pseudo TikTok et une clé gratuite. Rien d’autre à installer.
  • Tik360 ou TikFinity : si tu utilises déjà l’un de ces logiciels, lancé sur le même PC que le jeu.
Une seule source à la fois : te connecter à EulerStream arrête la réception Tik360.
Comment obtenir ma clé EulerStream ?
La clé est gratuite et se crée en une minute :
  1. Va sur eulerstream.com, crée ton compte ou connecte-toi, puis ouvre le Dashboard.
  2. Sur la page Euler Stream API, dans la partie API Keys, clique sur Create your first key (ou Create Key si tu as déjà une clé).
  3. Donne-lui un nom, par exemple « Panic Gum », puis clique sur Create API Key.
  4. Clique sur Click to Copy API Key : la clé est copiée, le message « Copied the API key to your clipboard » le confirme.
Où mettre la clé EulerStream dans le jeu ?
  1. Dans le menu du jeu, ouvre PARAMÈTRES, puis l’onglet TIKTOK.
  2. Choisis EULERSTREAM.
  3. Dans PSEUDO TIKTOK, écris ton pseudo sans le @.
  4. Clique dans CLÉ EULERSTREAM et colle ta clé (Ctrl + V).
  5. Clique sur CONNECTER.
La clé est enregistrée chiffrée sur ton PC : tu ne la saisis qu’une fois. Ensuite, il suffit de lancer ton live.
Le jeu reste sur « Déconnecté »
  • Ton live TikTok doit être lancé : le jeu ne reçoit rien tant que tu n’es pas en direct.
  • Vérifie ton pseudo : sans le @, sans espace, exactement comme sur TikTok.
  • Recolle ta clé : clique dans le champ, colle-la à nouveau puis clique sur CONNECTER.
  • Toujours rien ? Sur eulerstream.com, supprime la clé (Delete), crée-en une nouvelle et colle-la dans le jeu.
EulerStream est-il payant ?
Non, pas pour streamer : l’offre gratuite Community suffit pour tes lives. Ses limites (nombre de connexions par jour) s’affichent dans Rate Limits sur ton tableau de bord EulerStream.
Ma clé EulerStream est-elle en sécurité ?
Elle reste chiffrée sur ton PC et n’est envoyée qu’à EulerStream. Ne la partage jamais, même sur Discord : AstroLabs ne te la demandera pas. Si tu penses qu’elle a fuité, supprime-la sur eulerstream.com (Delete) et crées-en une nouvelle.
Utiliser Tik360 ou TikFinity
  1. Lance Tik360 ou TikFinity sur le même PC que le jeu, connecté à ton live TikTok.
  2. Dans le jeu, ouvre PARAMÈTRES, onglet TIKTOK, puis choisis TIK360.
  3. Importe le profil préparé pour le jeu, ou colle dans tes réactions « Webhook » les liens que le jeu te donne.
Le pseudo et l’avatar de tes viewers sont lus directement depuis Tik360 et TikFinity.
Mes jeux sont-ils liés à TikTok ?
Non : AstroLabs n’est pas affilié à TikTok. Les interactions du live passent par EulerStream, Tik360 ou TikFinity.
