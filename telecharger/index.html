Le launcher

Il installe tes jeux, les garde à jour et les lance en un clic. C’est aussi là que tu connectes ton live TikTok.

Télécharger pour Windows

Gratuit, pour Windows 10 et 11. Version 0.1.27, 3,1 Mo.

Installation

  1. 1

    Télécharge le launcher

    Le fichier AstroLabs_0.1.27_x64-setup.exe arrive dans ton dossier Téléchargements.

  2. 2

    Ouvre le fichier

    Windows peut afficher cet avertissement, car le launcher est récent. Clique sur Informations complémentaires, puis sur Exécuter quand même.

    Windows a protégé votre ordinateurMicrosoft Defender SmartScreen a empêché le démarrage d'une application non reconnue.
    Informations complémentaires
    Exécuter quand mêmeNe pas exécuter
  3. 3

    Connecte-toi

    Crée ton compte ou connecte-toi : c’est le même que sur ce site. Tes jeux achetés ici t’y attendent, et le launcher se met à jour tout seul.
