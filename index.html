Questions fréquentes

C’est quoi, AstroLabs ?
Un studio et un launcher pour Windows : des jeux pensés pour les lives TikTok, où le public agit sur la partie en direct.
Faut-il un compte ?
Oui, un compte AstroLabs gratuit. C’est le même sur le site et dans le launcher : un jeu acheté ici t’attend dans le launcher.
Comment payer ?
Par carte, via Stripe : AstroLabs ne voit jamais tes coordonnées bancaires. Tu peux aussi acheter depuis le launcher.
Windows affiche un avertissement à l’installation
C’est normal pour un logiciel récent : clique sur « Informations complémentaires » puis « Exécuter quand même ». Tout est expliqué sur la page Télécharger.
