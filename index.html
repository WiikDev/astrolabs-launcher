Tous tes jeux Astro Labs, au même endroit

Le launcher installe tes jeux, les garde à jour et les lance en un clic.

Télécharger pour Windows

Gratuit, pour Windows 10 et 11. Version 0.1.1, 2,8 Mo.

Installer en trois étapes

  1. Télécharge le launcher

    Le fichier AstroLabs_0.1.1_x64-setup.exe arrive dans ton dossier Téléchargements.

  2. Ouvre le fichier

    Windows peut afficher cet avertissement, car le launcher est récent. Clique sur Informations complémentaires, puis sur Exécuter quand même.

    Windows a protégé votre ordinateur Microsoft Defender SmartScreen a empêché le démarrage d'une application non reconnue.
    Informations complémentaires
    Exécuter quand mêmeNe pas exécuter

  3. Connecte-toi

    Crée ton compte avec ton adresse e-mail, ou connecte-toi. Le launcher se met ensuite à jour tout seul.
